# ThreePillars 🚀

**Build consistency. Track progress. Achieve more.**

ThreePillars is a lightweight, offline-first productivity tracker designed for students and developers who want to maintain consistency across three essential areas of personal and professional growth.

Instead of managing multiple productivity tools, ThreePillars brings your daily learning and progress into one simple dashboard.

## 🎯 The Three Pillars

### 1. DSA & Problem Solving
- Track Data Structures and Algorithms practice.
- Organize and monitor solved problems.
- Maintain a revision queue.
- Review your daily and long-term progress.

### 2. Java & Spring Boot
- Track Java learning progress.
- Monitor Spring Boot development activities.
- Maintain consistency in backend development.

### 3. Open Source Contributions
- Track open-source learning and contribution activities.
- Monitor progress across repositories.
- Stay consistent with your open-source goals.

## ✨ Features

- 📊 **Dashboard:** Get an overview of your daily progress.
- 💻 **DSA Tracker:** Manage and track solved problems.
- 🔄 **Revision Queue:** Keep track of problems that need revision.
- 🎯 **Three Pillars Checklist:** Monitor daily consistency across all three pillars.
- 📅 **Activity Calendar:** Visualize your coding consistency.
- 💾 **Local Data Storage:** Keep your personal progress stored locally.
- 🌐 **Offline-first:** Use your tracker without depending on a backend.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

No complicated installation or backend setup is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/ThreePillars.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ThreePillars
   ```

3. Open `index.html` in your browser.

That's it! Start tracking your progress.

## 💡 Project Philosophy

ThreePillars is built around a simple idea:

**Consistency matters more than intensity.**

The goal is not to spend hours organizing tasks or maintaining complicated productivity systems. The goal is to focus on meaningful work and make progress every day.
